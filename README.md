# UMBRASEC

Independent defensive security practice: detection engineering, with a focus on
AI-enabled and AI-targeted threats. Every claim sourced, every rule runnable.

- **[umbrasec.dev](https://umbrasec.dev)** - research, detection writeups and a free SMB security guide
- **[The Shipwreck](https://theshipwreck.beehiiv.com/subscribe)** - a free weekly briefing: what got exploited, what failure it created, and what to do on Monday
- **[umbrasec.dev repo](https://github.com/umbrasec-labs/umbrasec.dev)** - the site plus its tooling: Sigma and KQL rules, a zero-dependency CISA KEV monitor and a live KEV feed

Run by **0xdev1**. Seven years in GRC and detection engineering, including regulated
and public-sector environments; published under a handle because of that background.

Defensive in scope: no working exploits, malware or offensive tooling. Found an error?
[Open an issue](https://github.com/umbrasec-labs/umbrasec.dev/issues) - corrections are credited.
